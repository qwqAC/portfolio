# 阿冲的个人作品集网站

基于 Vue 构建的视觉设计作品集，本地可直接运行。

## 本地运行

直接用浏览器打开 `index.html` 即可（已配置 hash 路由，支持 file:// 协议）。

## 技术栈

- Vue.js (SPA)
- Lottie 动画
- 响应式设计
